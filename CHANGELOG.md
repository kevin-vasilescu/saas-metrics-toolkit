# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-23

### Added
- Monthly MRR, ARR, new, expansion, contraction and churned MRR
- Logo churn, gross revenue churn, NRR, GRR, ARPA, LTV, CAC, CAC payback, LTV:CAC and Quick Ratio
- Cohort retention matrix
- CSV validation with row-numbered messages
- Markdown, HTML, JSON and CSV reports
- `saas-metrics` CLI with `report`, `validate` and `sample` commands
- Deterministic synthetic data generator
